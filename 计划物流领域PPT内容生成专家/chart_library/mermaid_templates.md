# Mermaid 图模板库

> 用于流程图、架构图、时序图等文本型图表

---

## 1. 根因分析三层穿透

**模板：**

```mermaid
flowchart TD
    A[现象层<br/>{现象描述}] --> B[机制层<br/>{机制描述}]
    B --> C[系统层<br/>{系统描述}]
    
    A -->|表现| A1[{数据点1}]
    A -->|影响| A2[{影响范围}]
    
    B -->|因素1| B1[{因素1数据}]
    B -->|因素2| B2[{因素2数据}]
    B -->|因素3| B3[{因素3数据}]
    
    C -->|组织| C1[{组织问题}]
    C -->|流程| C2[{流程问题}]
    C -->|系统| C3[{系统问题}]
```

**适用场景：** 根因分析页、问题诊断页

## 2. 仓网架构图

**模板：**

```mermaid
flowchart TB
    subgraph CDC中央仓
        A1[惠州CDC]
        A2[天津CDC]
    end
    
    subgraph RDC区域仓
        B1[华东RDC<br/>无锡]
        B2[华南RDC<br/>广州]
        B3[华北RDC<br/>北京]
        B4[西南RDC<br/>成都]
        B5[华中RDC<br/>武汉]
    end
    
    subgraph FDC前端仓
        C1[上海FDC]
        C2[深圳FDC]
        C3[...更多城市]
    end
    
    subgraph 终端配送
        D1[B端客户]
        D2[C端消费者]
    end
    
    A1 --> B1
    A1 --> B2
    A2 --> B3
    A1 --> B4
    A1 --> B5
    
    B1 --> C1
    B2 --> C2
    
    C1 --> D2
    C2 --> D2
    B1 --> D1
    B2 --> D1
```

**适用场景：** 仓网规划页、系统规划页

## 3. 业务流程图

**模板（订单履约流程）：**

```mermaid
flowchart LR
    A[订单接收] --> B{订单类型判断}
    B -->|B端| C[RDC出库]
    B -->|C端| D[云仓出库]
    C --> E[干线运输]
    D --> F[末端配送]
    E --> G[客户签收]
    F --> G
    G --> H[回单确认]
    H --> I{是否有异常}
    I -->|是| J[异常处理]
    I -->|否| K[订单完成]
    J --> K
```

**适用场景：** 流程优化页、运营分析页

## 4. 项目里程碑时序图

**模板：**

```mermaid
gantt
    title 项目里程碑
    dateFormat  YYYY-MM-DD
    axisFormat  %m-%d
    
    section 阶段1
    需求分析     :a1, 2025-05-01, 14d
    方案设计     :a2, after a1, 14d
    
    section 阶段2
    系统开发     :b1, 2025-06-01, 30d
    测试验收     :b2, after b1, 14d
    
    section 阶段3
    试点上线     :c1, 2025-07-15, 14d
    全面推广     :c2, after c1, 30d
```

**适用场景：** 项目进展页、规划页

## 5. 组织架构图

**模板：**

```mermaid
flowchart TB
    A[计划物流部] --> B[仓储管理组]
    A --> C[运输管理组]
    A --> D[规划分析组]
    A --> E[系统支持组]
    
    B --> B1[CDC仓管理]
    B --> B2[RDC仓管理]
    B --> B3[库存优化]
    
    C --> C1[干线运输]
    C --> C2[末端配送]
    C --> C3[承运商管理]
    
    D --> D1[费用分析]
    D --> D2[网络规划]
    D --> D3[效率优化]
    
    E --> E1[WMS/TMS]
    E --> E2[BI报表]
    E --> E3[AI应用]
```

**适用场景：** 组织调整页、团队介绍页

## 6. 价值链图

```mermaid
    C --> D[管理提效]
    D --> E[总降本]
    
    A --> A1[合同谈判]
    A --> A2[集中采购]
    
    B --> B1[库存优化]
    B --> B2[仓租谈判]
    
    C --> C1[路径优化]
    C --> C2[装载率提升]
    
    D --> D1[自动化]
    D --> D2[流程优化]
    
    E --> E1[降本金额]
    E --> E2[费率下降]
```

**适用场景：** 降本成果页、效率提升页
