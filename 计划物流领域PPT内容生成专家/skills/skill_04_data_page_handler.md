# Skill 04：数据页总结与可视化

> 所属技能：计划物流领域PPT内容生成专家
> 版本：v1.0
> 功能：增强数据页的总结描述和可视化建议

---

## 一、功能定位

Skill 04是PPT生成的**第四阶段**，负责对数据页进行总结性描述增强，提供图表可视化建议，确保数据页不仅有数据，更有洞察和故事。

---

## 二、数据页处理流程

```mermaid
graph LR
    A[数据页内容] --> B[数据提取]
    B --> C[总结描述生成]
    C --> D[洞察提炼]
    D --> E[可视化建议]
    E --> F[输出增强内容]
```

## 三、数据页类型识别

### 3.1 数据页分类

| 数据页类型 | 识别特征 | 典型示例 |
|-----------|---------|---------|
| **费用分析页** | 包含费用率、费率、金额 | 全品类费用率达成 |
| **送达率页** | 包含C单/B单送达率 | 服务指标达成 |
| **货损分析页** | 包含货损率、屏裂率 | 货损改善 |
| **降本成果页** | 包含降本金额、比例 | 合同降本与运作降本 |
| **目标分解页** | 包含H1/H2/预算对比 | H2目标与预算 |
| **项目进展页** | 包含时间节点、完成度 | PTP项目、送装一体 |
| **区域分布页** | 包含区域数据 | 区域集中度分析 |
| **趋势分析页** | 包含时间序列数据 | 月度趋势 |

### 3.2 数据页识别规则

页面包含以下任一特征即为数据页：
- 包含数值表格（≥3行数据）
- 包含对比数据（H1 vs H2、实际 vs 预算）
- 包含时间序列数据
- 包含分类数据（按品类/区域/渠道）

## 四、总结描述生成

### 4.1 总结描述模板

#### 4.1.1 费用分析页总结

```markdown
【总结描述模板】

基于[时间周期]的数据分析，[指标名称]为[数值]，较[对比基准]的[数值] [变化趋势]了[变化幅度]。

其中，[分类1]的[指标]为[数值]，[状态说明]；
[分类2]的[指标]为[数值]，[状态说明]；
[分类3]的[指标]为[数值]，[状态说明]。

从结构上看，[关键发现1]；
从趋势上看，[关键发现2]；
从风险上看，[关键发现3]。

对H2的启示：
1. [启示1]
2. [启示2]
3. [启示3]
```

**示例**：
```markdown
基于2025年1-5月的数据分析，全品类费用率为3.68%，较预算3.70%基本持平，但同比增加0.12pp。

其中，智屏-TCL费用率为2.45%，优于预算0.07pp，表现良好；
空调费用率为4.78%，超预算0.23pp，是主要拖累项；
冰洗费用率为7.95%，超预算0.67pp，超标幅度最大。

从结构上看，智屏/雷鸟/乐华三大品类均优于预算，显示品类费用管控能力较强；
从趋势上看，空调费率从1月的4.55%上升至5月的4.78%，呈恶化趋势；
从风险上看，冰洗费率7.95%为全品类最高，且同比仅改善0.22pp，改善空间有限。

对H2的启示：
1. 空调费率是H2降本的关键突破口，需重点攻关云仓库存和ASP问题
2. 冰洗费率改善空间大但难度高，需与营销部门协同调整渠道结构
3. 智屏品类的成功经验（BC融合、智能补货）可向其他品类复制推广
```

### 4.2 洞察提炼方法

#### 4.2.1 对比洞察

```
对比维度 → 发现差异 → 解释原因 → 提出行动建议

示例：
对比维度：空调费用率4.78% vs 智屏2.45%
发现差异：空调费用率是智屏的2倍
解释原因：空调云仓库存高+ASP低+小批量订单多
行动建议：优化云仓策略+提升ASP+整合小批量订单
```

#### 4.2.2 趋势洞察

```
识别趋势 → 判断持续性 → 预测未来 → 提出预警

示例：
识别趋势：空调费率从1月4.55%上升至5月4.78%
判断持续性：若不干预，全年可能突破5%
预测未来：H2费用率可能达到5.2%
提出预警：需立即启动云仓优化和ASP提升措施
```

#### 4.2.3 结构洞察

```
拆解结构 → 识别异常 → 定位根因 → 提出方案

示例：
拆解结构：全品类费用率=智屏(40%)+空调(30%)+冰洗(20%)+其他(10%)
识别异常：空调占30%但仅贡献10%收入
定位根因：空调ASP低+云仓费用高
提出方案：提升空调ASP+优化云仓布局
```

## 五、可视化建议

### 5.1 图表类型推荐

#### 5.1.1 费用分析页

| 数据类型 | 推荐图表 | 理由 |
|---------|---------|------|
| 分品类费用率对比 | 柱状图 | 直观对比各品类差异 |
| 费用率时间趋势 | 折线图 | 展示月度变化趋势 |
| 费用结构占比 | 饼图/环形图 | 展示各品类占比 |
| 预算vs实际偏差 | 瀑布图 | 展示偏差构成 |

#### 5.1.2 送达率页

| 数据类型 | 推荐图表 | 理由 |
|---------|---------|------|
| 送达率达成情况 | 仪表盘图 | 直观展示达标状态 |
| 分渠道送达率 | 分组柱状图 | 对比各渠道差异 |
| 送达率趋势 | 折线图 | 展示时间趋势 |

#### 5.1.3 降本成果页

| 数据类型 | 推荐图表 | 理由 |
|---------|---------|------|
| 降本金额对比 | 柱状图 | 直观对比各类降本 |
| 降本进度 | 进度条图 | 展示完成进度 |
| 降本结构 | 饼图 | 展示降本构成 |

#### 5.1.4 目标分解页

| 数据类型 | 推荐图表 | 理由 |
|---------|---------|------|
| H1 vs H2目标 | 对比柱状图 | 直观对比变化 |
| 目标达成路径 | 漏斗图 | 展示路径和缺口 |
| 风险矩阵 | 散点图 | 展示风险分布 |

### 5.2 可视化设计规范

#### 5.2.1 颜色规范

| 数据类型 | 推荐颜色 | 说明 |
|---------|---------|------|
| 达标数据 | 绿色(#28A745) | 正向、积极 |
| 超标数据 | 红色(#DC3545) | 负向、预警 |
| 目标线 | 虚线灰色 | 参考基准 |
| 实际数据 | 蓝色(#005CA9) | TCL企业色 |
| 预算数据 | 橙色(#FF9900) | 对比参考 |
| 同比数据 | 浅蓝色 | 历史对比 |

#### 5.2.2 标注规范

```
图表必须包含：
- 标题：简洁明了，包含关键信息
- 数据来源：底部标注来源系统
- 注释：特殊数据点需注释
- 单位：明确标注数据单位
- 时间：标注统计周期
```

## 八、注意事项

1. **总结描述必须存在**：数据页不能只有表格，必须有总结描述
2. **洞察要有数据支撑**：每个洞察必须有具体数据支撑
3. **可视化建议要具体**：图表类型、数据维度、设计要点都要明确
4. **颜色要符合规范**：使用TCL蓝、绿色、红色等标准色
5. **避免过度可视化**：每页不超过2个图表，避免信息过载
6. **洞察要有行动建议**：不仅指出问题，还要给出行动方向
7. **总结描述不少于100字**：确保内容充实
