# Skill 05：输出格式化与审核

> 所属技能：计划物流领域PPT内容生成专家
> 版本：v1.0
> 功能：格式化输出最终.MD文档，执行审计合规检查，生成动态追问清单

---

## 一、功能定位

Skill 05是PPT生成的**第五阶段（最终阶段）**，负责将生成的内容整合为结构化的Markdown文档，执行最终审计合规检查，生成动态追问清单，并输出可用于审核的完整文档。

---

## 四、审计合规检查清单

### 4.1 数据自洽性检查

#### 4.1.1 费用率汇总检查

```
检查规则：
全品类费用率 = Σ(品类费用率 × 品类收入占比)

检查项：
□ 各品类费用率汇总是否等于全品类费用率
□ 各品类收入占比之和是否等于100%
□ 费用率偏差计算是否正确（实际-预算）
```

#### 4.1.2 降本金额检查

```
检查规则：
年度降本目标 = Σ(各降本措施金额)
净效果 = 降本金额 - 成本增加

检查项：
□ 各降本措施金额之和是否等于总降本目标
□ 净效果计算是否正确
□ 一次性降本是否标注
```

#### 4.1.3 目标一致性检查

```
检查规则：
H2目标 = H1实际 - 改善幅度 ± 风险调整

检查项：
□ H2目标是否有基期数据支撑
□ H2目标测算逻辑是否完整
□ 目标与措施是否匹配
```

### 4.2 目标SMART化检查

#### 4.2.1 SMART+ATM检查清单

| 维度 | 检查问题 | 通过标准 |
|------|---------|---------|
| **S-具体** | 目标是否具体到品类/区域/渠道？ | 有明确分类 |
| **M-可衡量** | 目标是否可量化？有具体数值？ | 有数字 |
| **A-可达成** | 目标是否现实可行？ | 有基期+测算逻辑 |
| **R-相关性** | 目标是否与战略方向一致？ | 有战略关联 |
| **T-时限** | 目标是否有明确时间节点？ | 有日期 |
| **A-行动** | 目标是否包含具体行动措施？ | 有措施列表 |
| **M-里程碑** | 目标是否有关键节点？ | 有里程碑 |

#### 4.2.2 目标测算逻辑检查

```
检查规则：
目标必须有测算依据，不能凭空设定

检查项：
□ 目标值是否有基期数据
□ 目标值是否有测算公式
□ 测算公式是否有数据来源
□ 风险调整是否说明
□ 敏感性分析是否完成
```

### 4.3 完整性检查

#### 4.3.1 占位符检查

```
检查规则：
禁止出现任何形式的占位符

检查项：
□ "描述XXX" → 替换为具体描述
□ "X.xx%" → 替换为具体数值
□ "待定" → 替换为具体数据或删除
□ "详见XX页" → 补充具体内容或删除
□ 空白数据 → 补充数据或说明原因
```

#### 4.3.2 责任人检查

```
检查规则：
每项措施必须明确责任人

检查项：
□ 每项措施是否有明确的责任人
□ 责任人是否在职
□ 责任人是否有权执行
□ 责任人是否知情
```

### 4.4 逻辑推导检查

#### 4.4.1 叙事链条检查

```
检查规则：
叙事链条必须完整，禁止逻辑跳跃

检查项：
□ 每页有上页承接
□ 每页有本页核心
□ 每页有下页预告
□ 页面间逻辑推导连续
□ 无逻辑跳跃
```

#### 4.4.2 推导链条完整性检查

```
检查规则：
必须包含完整的推导链条

标准链条：
现状 → 问题 → 根因 → 措施 → 目标 → 资源

检查项：
□ 现状描述有数据支撑
□ 问题分析有根因穿透
□ 措施与问题匹配
□ 目标与措施匹配
□ 资源与目标匹配
```

## 五、动态追问清单生成

### 5.1 P0级问题（必须回答）

#### 5.1.1 触发条件

- 目标无基期数据
- 降本金额无成本增加
- 单人负责项目>60%
- 区域集中度>50%
- 系统建设无时间节点
- 组织调整无影响评估

#### 5.1.2 示例

```markdown
### P0级问题

#### P0-1：H2目标3.53%的测算依据缺失
- **涉及页面**：P9
- **问题描述**：H2目标3.53%的测算逻辑不完整，仅给出"同比不增加3.54%"的挑战目标，未展示如何从H1实际3.77%推导至3.53%的具体路径。
- **影响**：影响管理层对H2目标可信度的判断
- **建议确认方式**：
  1. 提供H2目标测算公式
  2. 列出各降本措施的贡献度
  3. 说明风险调整项
- **追问**：请补充H2目标3.53%的详细测算依据，包括：①各降本措施贡献度；②收入增长预期；③风险调整项。

#### P0-2：600万油价联动是否已纳入H2目标
- **涉及页面**：P8
- **问题描述**：合同降本2093万中，600万油价联动费用是否已纳入H2目标？净效果1493万=2093-600，但H2目标是否考虑了这600万？
- **影响**：影响H2目标可信度
- **建议确认方式**：确认600万是否作为H2目标的基线调整
- **追问**：600万油价联动费用是否已纳入H2目标？如果未纳入，H2实际目标应为3.53%+油价联动影响。
```

### 5.2 P1级问题（建议补充）

#### 5.2.1 触发条件

- 数据可进一步细化
- 分析可更深入
- 案例可更丰富

#### 5.2.2 示例

```markdown
### P1级问题

#### P1-1：空调费率4.92%→4.45%的分解措施
- **涉及页面**：P4、P9
- **问题描述**：空调费率需从4.92%降至4.45%，但具体通过哪些措施实现？措施贡献度如何分解？
- **建议补充内容**：
  1. 云仓优化预计贡献Xpp
  2. ASP提升预计贡献Xpp
  3. 运输成本优化预计贡献Xpp
  4. 各项措施合计是否等于0.47pp

#### P1-2：PTP项目延期风险评估
- **涉及页面**：P10
- **问题描述**：PTP项目已延期2个月，是否有Plan B？延期对H2目标的影响？
- **建议补充内容**：
  1. PTP项目延期的具体原因
  2. 8月30日上线是否现实
  3. 延期对H2目标的量化影响
  4. Plan B方案
```

## 八、注意事项

1. **审计检查必须全面**：不能遗漏任何检查项
2. **追问清单要具体**：每个问题都要有具体的涉及页面和建议
3. **输出格式要规范**：使用Markdown标准格式，便于阅读和后续处理
4. **P0级问题必须处理**：不回答P0级问题，报告不能算完成
5. **数据汇总要完整**：附录中的数据汇总表必须包含所有关键指标
6. **术语表要完整**：所有使用的术语都要在术语表中解释
7. **版本管理**：每次更新都要记录版本号和更新内容
