# Skill 01：输入解析与术语提取

> 所属技能：计划物流领域PPT内容生成专家
> 版本：v1.0
> 功能：解析用户输入，提取关键信息，执行术语校验

---

## 一、功能定位

Skill 01是PPT生成的**第一阶段**，负责接收用户输入（文本/数据/主题），将其转化为结构化的信息素材库，为后续大纲生成和内容填充提供基础。

---

## 二、输入处理流程

```mermaid

    E --> F[输出素材库]
```

## 三、输入类型识别

### 3.1 支持的输入类型

| 类型 | 识别特征 | 处理方式 |
|------|---------|---------|
| **完整报告** | 包含标题、章节、数据表格 | 直接提取全部内容 |
| **数据表格** | 纯数字/表格内容 | 提取数据+推断上下文 |
| **主题描述** | 简短文字描述 | 基于主题生成通用框架+追问 |
| **大纲草稿** | 已有页面标题列表 | 基于大纲丰富内容 |
| **多份材料** | 多次上传 | 整合分析 |

### 3.2 报告类型识别（8种）

根据输入内容自动识别报告类型：

| 报告类型 | 识别特征 | 关键词 |
|---------|---------|--------|
| **复盘规划型** | 包含H1/H2、回顾/规划 | "H1总结""H2规划""复盘" |
| **周会型** | 周度数据、周环比 | "周会""周报""周度" |
| **现状规划型** | 现状描述+变革方案 | "现状""变革""推广" |
| **项目复盘型** | 项目背景+执行+成果 | "项目""复盘""成果" |
| **战略规划型** | 战略复盘+未来规划 | "战略""规划""目标分解" |
| **组织+H2规划型** | 组织调整+H2目标 | "组织调整""H2目标" |
| **预算型** | 年度预算+费用点位 | "预算""费用点位""费率" |
| **跨报告趋势分析** | 多份报告对比 | "趋势""对比""分析" |

## 五、术语校验

### 5.1 术语库匹配

将提取的文本与术语库进行匹配，标记已识别术语和待确认术语。

#### 5.1.1 指标类术语

| 术语 | 说明 | 常见变体 |
|------|------|---------|
| 费用点位/费用率 | TCL内部标准术语 | 费率、物流费率 |
| C单24H送达率 | C端订单24小时送达比例 | C端时效 |
| B单48H送达率 | B端订单48小时送达比例 | B端时效 |
| 屏裂率 | 屏幕破损比例 | screen破损率 |
| 货损率 | 货物损坏比例 | 机损率、箱损率 |
| 整车率 | 整车运输比例 | - |
| 直发率 | 工厂直发比例 | - |
| 商返率 | 商品退货率 | - |
| VOC单量 | 客户投诉单量 | - |
| 周转天数 | 库存周转天数 | - |

#### 5.1.2 运作类术语

| 术语 | 说明 |
|------|------|
| CDC | 中央配送中心 |
| RDC | 区域配送中心 |
| BC一体/BC融合 | B端C端融合运作 |
| 一盘货 | 统仓统配模式 |
| 送装一体 | 送货+安装一体化 |
| 线路拉直 | 优化运输线路 |

#### 5.1.3 系统类术语

| 术语 | 说明 |
|------|------|
| S计划 | TCL内部降本专项 |
| 奚仲项目 | - |
| AI×BI | AI与BI结合应用 |
| WMS | 仓储管理系统 |
| TMS | 运输管理系统 |
| TOF系统 | - |
| TCLaw | TCL内部AI工具 |

### 5.2 待确认术语处理

当遇到未在术语库中收录的词汇时：

1. **判断是否为行业通用表达**：若是，直接通过
2. **标记为「待确认术语」**：在输出中单独列出
3. **给出初步推测**：基于上下文推测可能含义
4. **建议确认方式**：建议用户补充确认

**示例**：
```
待确认术语：
- "commit率"（第3页）：可能为内部术语"承诺达成率"，建议确认
- "FDC"（第4页）：可能为"前端配送中心"，建议确认具体含义
```

## 八、注意事项

1. **数据完整性**：确保所有关键数据都被提取，不遗漏
2. **术语准确性**：遇到不确定术语时标记为「待确认」，不猜测
3. **多份材料整合**：当用户上传多份材料时，需识别时间线和关联性
4. **数据冲突检测**：同一指标在不同位置数值不一致时，标记矛盾
5. **隐私保护**：不涉及个人隐私信息提取
